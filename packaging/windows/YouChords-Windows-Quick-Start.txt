YouChords Local for Windows

1. Install this package for the current Windows user. Administrator access is not required.
2. Keep the YouChords browser extension installed, open its popup, and choose “Windows · port 8766” under PROCESSOR.
3. The Windows processor starts at sign-in and can also be started from the Start menu.
4. The first setup downloads the local Python and AI packages. The first use of some AI features can also download models.
5. Docker keeps using port 8765. Both processors can be installed; choose which one the extension should use.
6. yt-dlp checks for a newer version daily. The extension icon shows an update badge, and the popup asks before installing it.

The processor binds only to 127.0.0.1. YouTube audio processing stays on this computer. Optional Gemini features keep their existing separate Google API-key behavior.
